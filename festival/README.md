## 何ができるアプリか（3行）

ハロウィンをテーマにした、バブルを発射して遊ぶパズルゲームです。  
同じキャラクターのバブルを3つ以上つなげて消し、できるだけ高いスコアを目指します。  
難易度、特殊な「日専祭バブル」、ランキング、アバター、BGM・効果音などを入れ、何度も挑戦したくなるゲームを目指します。

## 画面

現在、以下の画面を作成する予定です。

- タイトル画面
- アバター選択画面
- ロビー画面
- ゲーム画面
- 結果画面
- ランキング画面
- 設定画面

### タイトル画面

アプリを起動した時に最初に表示される画面です。

日専祭とハロウィンの雰囲気が伝わるデザインにし、STARTボタンからゲームを始めます。

### アバター選択画面

おばけ、かぼちゃ、黒猫、魔女など、ハロウィンをイメージしたキャラクターの中から好きなアバターを選べるようにします。

選んだアバターはランキングにも表示する予定です。

### ロビー画面

プレイヤー情報と選択したアバターを表示し、

- EASY
- NORMAL
- HARD

の3つから難易度を選択します。

また、ランキング画面や設定画面にも移動できるようにします。

### ゲーム画面

画面下からバブルを発射し、同じキャラクターのバブルを3つ以上つなげると消える仕組みにします。

かぼちゃ、おばけ、黒猫などの「かわいいけど少し怖い」ハロウィンキャラクターを使用します。

通常のバブル以外に、日専祭限定の特殊な「日専祭バブル」も登場させる予定です。

また、ゲーム中には危険なクモも登場します。クモに触れると画面上のバブルが一気に爆発し、ゲームオーバーになる仕組みを考えています。

### 結果画面

ゲーム終了後に、

- スコア
- 消したバブルの数
- コンボ数
- 順位
- ベストスコア

などを表示します。

RETRYでもう一度挑戦したり、HOMEからロビーに戻ったりできるようにします。

### ランキング画面

プレイヤーの

- アバター
- ニックネーム
- スコア
- 順位

を表示します。

他のプレイヤーのスコアを見ることで、「もっと高いスコアを取りたい」と思ってもらい、何度も挑戦してもらえるようにします。

### 設定画面

- BGM ON / OFF
- 効果音 ON / OFF
- アバター変更
- ニックネーム変更

などを設定できるようにする予定です。

（スクリーンショットは画面完成後に追加します。）

## 生成AIの使い方（どの場面で、どう使ったか）

ChatGPTを使って、ゲームの企画、画面構成、機能の整理、3人で開発するための担当分けを考えました。

また、3人が別々に作成したコードを最後に1つのXcodeプロジェクトにまとめやすくするため、

- `TitleView`
- `LobbyView`
- `GameView`
- `ResultView`
- `RankingView`
- `SettingsView`

などのView名や、画像・BGM・効果音のファイル名を事前に統一しました。

Xcodeでコードの骨組みを作る時にも生成AIを利用し、`Difficulty` や `GameResult` などの共通データの構造を考えています。

また、ゲームの画面構成や遊び方をチーム内で共有するため、生成AIを使ってイメージ画像やフロー図も作成しました。

ただし、AIで作成した画像は画面構成を確認するための参考として使用し、実際のゲームデザインはそのままコピーせず、チームでハロウィンらしい統一感のあるデザインに調整します。

エラーが発生した場合は、エラー内容を生成AIに確認し、原因を理解しながら修正しています。

生成されたコードもそのまま使用するのではなく、内容を確認し、授業で学んだSwift / SwiftUIの知識と照らし合わせながら修正して使用します。

## 展示で工夫した点

日専祭では、初めて遊ぶ人でもすぐにルールが分かるように、

**「バブルを発射して、同じキャラクターを3つ以上つなげて消す」**

というシンプルな操作を基本にします。

ハロウィンをテーマに、かぼちゃ、おばけ、黒猫などの「かわいいけど少し怖い」キャラクターを使用し、日専祭の会場で見ても楽しいデザインを目指します。

また、通常のバブルだけではなく、**日専祭限定の「日専祭バブル」**を登場させ、通常とは違う特別な効果やボーナスを付ける予定です。

さらに、クモに触れると画面上のバブルが一気に爆発してゲームオーバーになる仕組みを入れ、単純にバブルを消すだけではない緊張感も作ります。

プレイヤーは好きなハロウィンキャラクターのアバターを選ぶことができ、そのアバターとニックネームをランキングに表示します。

ゲーム終了後にはスコアとランキングを表示し、他のプレイヤーの記録を見ることで、

「もう一回やって記録を更新したい」  
「ランキングでもっと上に行きたい」

と思ってもらえるようにします。

また、ロビー画面とゲーム画面では雰囲気の異なるBGMを使用し、バブルの発射、消去、特殊バブル、クモ、ゲームオーバーなどにも効果音を付け、日専祭の展示で見ている人にもゲームの楽しさが伝わるように工夫します。
