## 何ができるアプリか（3行）

ハロウィンをテーマにした反射神経ゲームです。  
画面に表示されたお題に合わせて、正しいキャラクターをすばやくタップし、制限時間内に高得点を目指します。  
難易度選択、加点・減点、ライフ、ランキング、称号、BGM・効果音などを入れ、何度も挑戦したくなるゲームを目指します。

## 画面

現在、以下の画面を作成する予定です。

- タイトル画面
- ロビー画面
- ゲーム画面
- 結果画面
- ランキング画面
- 設定画面

タイトル画面では日専祭・ハロウィンらしい雰囲気を出し、ロビー画面では EASY / NORMAL / HARD の難易度を選択できるようにします。

ゲーム画面では、かぼちゃ・おばけ・コウモリなどのキャラクターが表示され、お題に合ったキャラクターをタップします。

## 展示で工夫した点

日専祭では短い時間でもすぐに遊び方が分かるように、操作を「表示されたキャラクターをタップする」という簡単なルールにしました。

EASY / NORMAL / HARD の難易度を用意し、ゲームに慣れている人も初心者も遊べるようにします。

正しいキャラクターをタップすると加点し、間違えると減点します。また、おじゃまキャラクターとしてクモを登場させ、一定時間以内に対応できないとライフが減る仕組みにします。

ゲーム終了後にはスコアとランキングを表示し、上位者にはゲーム内の特別な称号を表示します。

- 1位：日専祭ハロウィン王
- 2位：ハロウィンマスター
- 3位：スピードハンター

ランキングを見ることで、「もう一度挑戦してもっと高い点を取りたい」と思ってもらえるようにします。

また、ロビー画面とゲーム画面では異なるBGMを使用し、正解・不正解・クモ・ゲーム終了時などにも効果音を付けて、ハロウィンらしい雰囲気とゲームの緊張感を出す予定です。
